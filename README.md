# Website Profil Pribadi — Assa

Website profil pribadi dengan tema soft sage, responsif untuk HP dan laptop.

## Isi folder
- `index.html` — struktur dan isi website
- `style.css` — desain, warna, dan tata letak
- `script.js` — interaksi menu dan tahun otomatis
- `assets/memasak-1.jpg` — foto kegiatan memasak yang dikirim

## Cara memasang di GitHub Pages
1. Ekstrak file ZIP ini.
2. Buat repository baru di GitHub.
3. Upload seluruh isi folder hasil ekstrak (bukan folder ZIP-nya).
4. Pastikan `index.html` berada di bagian paling luar/root repository.
5. Buka **Settings → Pages**.
6. Pada bagian Build and deployment, pilih **Deploy from a branch**.
7. Pilih branch `main` dan folder `/ (root)`, lalu tekan **Save**.
8. Tunggu proses selesai. Website akan memiliki alamat `https://username.github.io/nama-repository/`.

## Mengubah foto galeri
Simpan foto baru di folder `assets`, lalu tambahkan elemen `<img>` di bagian `gallery-grid` pada `index.html`.

## Catatan privasi
Website ini disiapkan untuk publik. Nomor HP, email pribadi, dan alamat rumah lengkap tidak dicantumkan agar tidak mudah disalahgunakan. Profil hanya menampilkan domisili umum: Blitar, Jawa Timur.
